교육과정: 2026학년도 고3 · 2015 개정 인공지능 기초. 핵심 [12인기02-09] 딥러닝의 개념을 이해하고, 활용 분야를 탐색한다. 연계 [12인기03-07], [12인기03-08]. Q2 개념 설명·Q6 활용 탐색·Q3 실험 평가로 연결한다. 수준별 피드백은 자체 설계안이며 공식 성취수준/학교 승인 평가계획이 아니다. 학교 평가계획 원문 확인이 남아 있다.

학과 연계는 학교 공식 소개의 PLC, 자동화 설비, 전기설비 유지보수 내용에 기반합니다. 학교 사이트의 학과 명칭 표기가 서로 다른 부분이 있어 요청한 ‘전기제어과’를 사용했습니다. 학교 공식 발행 자료는 아닙니다.

## 데이터·학습 구현

`model.js`에 JavaScript로 작성한 다층 퍼셉트론(3→6→4→1), tanh 은닉층, sigmoid 출력, 이진 교차 엔트로피, 역전파와 확률적 경사하강법을 구현했습니다. 학습률 0.025, 700 epoch, 초기 난수 seed 42를 고정합니다. 화면에 미리 정해진 성능을 표시하는 시연이 아니라, 브라우저에서 실제 가중치를 학습하고 성능을 계산합니다.

- 학습: seed 31, 80개, 정상/이상 각 40개
- 조건 A: 낮은 온도 정상과 높은 온도 이상
- 조건 B: 높은 온도 정상과 낮은 온도 이상도 포함
- 새 조건 평가: seed 982, 40개, 정상/이상 각 20개
- 정규화: `(temperature - 25) / 65`, `current / 10`, `vibration / 8`
- 정답은 합성 데이터 생성 시 정한 상태이며, 온도만으로 결정하지 않습니다.
- 진동 범위를 상태별로 분리한 단순한 교육용 데이터입니다. 규칙 기반 모델도 잘 분류할 수 있습니다. 딥러닝의 우월성을 주장하지 않습니다.
- 데이터 크기·센서 범위·모델 구조·수업 시간은 자체 설계값입니다. 실제 센서 측정, 실제 설비 안전 기준, 공인 성능 결과가 아닙니다.
- 출력 점수는 보정된 고장 확률이 아닙니다. 평가 데이터를 반복 관찰·조정하면 검증 데이터로 사용한 것이므로, 실제 배포 성능 판단에는 별도 미사용 시험 데이터가 필요합니다.

검증 실행: `node test.cjs`

| 조건 / 임계값 | 학습 정확도 | 평가 정확도 | TN | FP | FN | TP | 이상 재현율 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| A / 0.50 | 100% | 85% | 15 | 5 | 1 | 19 | 95% |
| B / 0.50 | 100% | 100% | 20 | 0 | 0 | 20 | 100% |

위 값은 이 저장소 코드의 고정 시드 합성 데이터 계산 결과이며, 현장 성능을 나타내지 않습니다.

## 실행 및 배포

`index.html`을 직접 열거나 정적 HTTP 서버로 제공할 수 있습니다. GitHub Pages는 `main` 브랜치의 루트(`/`)를 게시합니다. `.nojekyll`을 포함하여 정적 파일을 그대로 제공합니다. 빌드 과정과 서버가 필요하지 않습니다.

PDF 재생성은 `python build_pdf.py`로 수행합니다. Python 패키지 `reportlab`과 Windows 맑은 고딕 폰트가 필요합니다. 다른 운영체제에서는 스크립트의 폰트 경로를 해당 한글 폰트 파일로 변경하세요. 제공된 PDF는 한글 글꼴을 포함합니다.

| 학습 성능만 보고 성공이라 판단할 위험 | 별도 조건 평가와 혼동 행렬을 제공. 실제 학습 100%, 평가 85%의 차이를 재현 |
| 높은 모델 점수를 실제 고장 확률로 오해 | 보정되지 않은 점수라고 명시 |

| PDF 페이지 넘침 | 생성 스크립트의 여백 검사에서 발견, 문구·간격 조정 후 재생성 |
| 브라우저 UI 검토 권한 제한 | Edge 제어가 승인되지 않아 실제 브라우저 화면 조작 검증은 미완료. 모델 검사·DOM 기능 검사·PDF 이미지 검토·배포 HTTP 검증과 구분 |

‘오류 없음’을 보증하지 않습니다. 검사 결과와 남은 한계를 [검증 기록](VALIDATION.md)에 명시합니다. 실제 수업 전 사용하는 기기에서 PDF 저장과 한 차례 A/B 학습을 확인하는 것이 좋습니다.
