이미지 분류나 소리 분류 중 관심 분야를 고르세요. 필요한 데이터와 원하는 출력을 연결하고, 딥러닝을 적용할 이유와 확인할 한계를 제안하세요. 아래 활동은 탐색용 설계 과제이며 실증된 설비 사례가 아닙니다.

연계 기준: [12인기03-07] 훈련 데이터와 테스트 데이터의 역할을 비교한다. / [12인기03-08] 훈련 데이터를 분류 모델의 학습에 적용하고, 테스트 데이터를 이용하여 성능을 평가한다.

도달 증거: Q2 개념 설명 + Q6 활용 탐색 + Q3 실험 기록. 모둠 활동 후 Q2와 Q6는 학생 각자가 자기 말로 설명하여 확인합니다.

수준별 피드백 기준 보기 · 수업용 설계안

아래는 제작자가 성취기준에 맞춰 작성한 형성평가 기준입니다. 국가 공통 또는 학교 승인 성취수준이 아니며 A·B·C 성적과 직접 대응하지 않습니다. 학교의 2026학년도 평가계획 원문은 미확인 상태입니다.

평가 요소심화 도달기본 도달보완 지도
개념 설명 · Q2여러 은닉층과 가중치 학습을 연결하여 딥러닝을 설명하고 PLC 규칙과 비교한다.신경망이 데이터로 학습한다는 개념을 설명한다.입력·은닉층·출력 그림과 문장 틀로 개념 설명을 다시 작성한다.
활용 탐색 · Q6입력 데이터·해결할 문제·출력·딥러닝 적용 이유와 한계를 연결한다.활용 분야와 입력·출력을 연결하여 설명한다.제시된 분야를 골라 입력과 출력을 짝짓고 이유를 보완한다.
학습·평가 · Q3훈련·평가 데이터의 역할을 구분하고 A/B 수치와 오류 사례를 해석한다.훈련·평가 결과를 기록하고 정확도를 비교한다.도움을 받아 학습·평가를 실행하고 결과표를 완성한다.

04 / TEAM WORKSHEET

클릭한 결과를, 나의 근거로.

입력 내용은 이 브라우저에만 저장됩니다. 공용 기기에서는 저장 후 지워 주세요.

자동 저장 준비
01 · 예측 / 0–8분

뜨거운 모터는 모두 이상일까요?

내 예상과 이유를 쓰고, 확인하고 싶은 센서값을 골라 보세요.

02 · 연결 / 8–18분

센서에서 경보까지 설명해 보세요.

여러 은닉층과 가중치 학습을 연결해 딥러닝을 설명하고, 사람이 조건을 정하는 PLC 규칙과 비교하세요.

03 · 비교 / 18–38분

A와 B의 결과는 어떻게 달랐나요?

임계값을 0.50으로 맞추고 비교표를 기록하세요. 오분류 데이터 ID와 수치를 근거로 설명하세요.

04 · 판단 / 38–46분

오경보와 이상 누락, 무엇을 줄일까요?

생산팀·정비팀의 입장을 각각 써 보고, 임계값 변경 결과로 자신의 제안을 뒷받침하세요.

05 · 개선 / 46–52분

‘딸깍’으로 해결되지 않은 문제는?

데이터 다양성·정답 오류·새 환경 중 하나를 골라 문제 → 증거 → 개선 → 재검증 계획을 쓰세요.

06 · 퇴장권 / 52–60분

딥러닝을 다른 분야에 활용한다면?

모터 진단 외에 이미지 분류 또는 소리 분류를 선택하세요. 입력 데이터 → 해결할 문제 → 출력, 딥러닝을 적용할 이유와 한계를 쓰세요. 제안과 실제 적용 사례를 구분하고, 실제 사례라면 출처를 적으세요.

마지막 확인 · 학습 정확도만 높으면 바로 배포해도 된다?

자신의 판단을 선택해 보세요.

개념·활용 탐색·학습 평가의 활동 및 피드백 기준은 학습 목표와 평가 연결표에서 확인하세요. 공식 성취수준과 학교 평가계획은 확인 전이며, 수업용 형성평가 기준을 공식 기준으로 사용하지 않습니다.

운영 팁과 반론

“규칙으로도 분류되는데 꼭 딥러닝인가?” → 맞습니다. 이 합성 데이터에서는 간단한 규칙도 충분할 수 있습니다. 오늘은 신경망 학습과 검증의 원리를 탐구하며, 실제 도입 시 규칙 기반 방식과 성능·비용을 비교해야 합니다.

“학습을 더 하면 해결되지 않을까?” → 빠진 운전 조건은 반복 학습만으로 보충되지 않습니다. 다양한 데이터와 독립적인 평가가 필요합니다. A의 실패는 의도적으로 제한한 학습 조건의 영향이며, 이 결과만으로 과적합이라고 단정하지 않습니다.
