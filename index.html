01 / COLLECT

먼저, 세 가지를 가르쳐 주세요.

얼굴 대신 손과 배경을 담으세요. 거리와 각도를 바꾸어 각 종류를 5장 이상 모으세요. 종류별 최대 40장입니다. 이 개수는 실습 설정이며 성능 보장 기준이 아닙니다.

카메라를 켜거나 아래에서 사진 파일을 선택하세요.

카메라는 켜기 버튼을 눌러야 요청합니다.

HTTPS 또는 localhost에서 카메라를 사용할 수 있습니다. 카메라 사용이 어렵다면 사진 파일로 진행하세요.

02 / TRAIN

사진에서 구분하는 방법을 배워요.

이미 학습된 신경망이 사진의 특징을 추출하고,
우리가 모은 사진으로 마지막 분류기를 학습합니다.

첫 학습 시 사전학습 모델을 내려받으므로 인터넷이 필요합니다. 사진은 페이지 메모리에서 처리하며 외부로 전송하는 기능은 없습니다.

세 종류의 사진을 각각 5장 이상 모아 주세요.

학습 결과는 실행 후 표시됩니다.

03 / TRY SOMETHING NEW

처음 보는 손도 알아볼까요?

학습에 넣지 않은 새 사진으로 확인하세요. 지금 모습 예측을 누를 때 한 번 판단합니다. 자동으로 계속 촬영하지 않습니다.

테스트 사진은 학습 사진에 자동 추가되지 않습니다.

학습을 마치면 예측할 수 있어요.
